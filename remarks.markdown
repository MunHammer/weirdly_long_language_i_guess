# WeirdlyLongLanguageIGuess

## How to Run

1. Set up [Rust](https://rust-lang.org/learn/get-started/)
2. Build this project
```shell
  cd wherever/you/put/this/

  cargo build --release
  mv target/release/weirdly_long_language_i_guess ./

  # The binary will now be in your current directory

  ./weirdly_long_language_i_guess --help
```

## Examples
- [hello.veryverylong](long_examples/hello.veryverylong): Prints "Hello, World!".
- [fibonacci.veryverylong](long_examples/fibonacci.veryverylong): Prints the Fibonacci sequence.
